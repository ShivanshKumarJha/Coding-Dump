Upper Bounded wildcard : <? extends UpperBoundClassName> i.e. class Name and below  -> When you want to read values safely
Lower Bounded wildcard : <? super LowerBoundClassName> i.e. class Name and above -> When you want to write/add values safely
Unbounded wildcard : <?> only you can read
